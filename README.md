# CodeAlpha_WebScraping

## Project Overview
This project uses Python and BeautifulSoup to scrape book data from a public website.

## Technologies Used
- Python
- Requests
- BeautifulSoup
- Pandas
- Google Colab

## Data Collected
- Book Title
- Price
- Rating
- Availability

## Output
The scraped data was converted into a CSV dataset.

## Project Files
- CodeAlpha_WebScraping.ipynb
- CodeAlpha_Books_Dataset.csv
